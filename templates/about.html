Veb-sayt nima?

Veb-sayt — bu internet orqali brauzer yordamida ochiladigan, matn, rasm va boshqa ma'lumotlarni o'z ichiga olgan sahifalar to'plamidir. Har bir sayt HTML, CSS va JavaScript kabi texnologiyalar yordamida yaratiladi.

Sayt qanday qismlardan iborat?

HTML

Saytning skeleti — matn, rasm va tugmalar shu yerda joylashadi.

CSS

Saytning ko'rinishi — ranglar, shriftlar va joylashuvni belgilaydi.

JavaScript

Saytga interaktivlik qo'shadi — tugmalar, animatsiya va boshqalar.

Sayt qanday ishlaydi?

Siz brauzerda manzilni kiritganingizda, so'rov serverga yuboriladi. Server esa kerakli HTML sahifani tayyorlab, brauzerga qaytaradi va siz uni ekranda ko'rasiz.

Dasturlash Tillari Haqida

HTML

Saytning strukturasini yaratish uchun ishlatiladi. Teglar yordamida matn, rasm, video joylashtiriladi.

CSS

Ranglar, shriftlar va joylashuvni belgilaydi. Flexbox va Grid kabi zamonaviy usullar mavjud.

JavaScript

Saytga tugmalar, animatsiya va forma tekshiruvi kabi interaktivlik qo'shadi.

Python

Server tomonidagi mantiqni yozish uchun ishlatiladi. Django, Flask kabi freymvorklar mavjud — aynan shu loyiha ham Python (Django) asosida qurilgan.

PHP

Dinamik veb-sahifalar yaratish uchun mo'ljallangan backend tili. WordPress kabi tizimlar shu tilda ishlaydi.

SQL

Ma'lumotlar bazasi bilan ishlash uchun ishlatiladi. MySQL, PostgreSQL kabi tizimlarda qo'llaniladi.
